# ☁️ Loruki – Cloud Hosting Website

A responsive cloud hosting website built using **HTML5 and CSS3**. Loruki provides a clean and modern interface to showcase cloud hosting services, features, documentation, and deployment capabilities.

## 🌐 Live Demo

[View Website](#)

## 📸 Project Overview

Loruki is a cloud hosting platform website developed to practice and demonstrate frontend web development skills. The project focuses on responsive layouts, modern UI design, CSS Flexbox, CSS Grid, and reusable styling techniques.

## ✨ Features

- **Home Page:** Landing page with a navigation bar, hero section, demo request form, and hosting statistics.
- **Features Page:** Dedicated page showcasing the platform's hosting features.
- **Documentation Page:** Documentation layout with navigation and content sections.
- **Responsive Design:** Layout adapts to different screen sizes.
- **Modern UI:** Clean design with cards, buttons, icons, and structured sections.
- **CSS Animations:** Hover effects and transitions for interactive elements.
- **Reusable CSS:** Common utility classes for consistent styling.

## 🛠️ Technologies Used

- HTML5
- CSS3
- CSS Flexbox
- CSS Grid
- Font Awesome Icons
- Google Fonts

## 🚀 Getting Started

Follow these steps to run the project locally.

### 1. Clone the Repository

```bash
git clone https://github.com/justinj04/Loruki-website.git
```

### 2. Navigate to the Project Directory

```bash
cd Loruki-website
```

### 3. Open the Website

Open `index.html` in your preferred browser.

Alternatively, use the **Live Server** extension in Visual Studio Code for local development.
